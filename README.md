# Sum Match

A number-pairing puzzle styled as a soft, card-based dashboard: a blue-gradient hero card, rounded stat cards, and pill buttons, with the board itself living in a dark terminal-style panel where every digit keeps its own distinct color.

## Rules

Tap two tiles whose values add up to the target sum. Matched pairs clear from the board; clear all 8 pairs to win. A wrong pair just bounces back &mdash; no penalty beyond a tap.

## Features

- Three target sums to cycle through (10, 8, 12) via the header button
- A freshly generated, always-solvable set of pairs every round
- Live "matched" and "pairs left" stats, plus a taps counter and timer
- New Game (fresh values) and Reshuffle (same values, new layout) controls
- A completion screen with your final tap count and time

To play, open `sum-match-puzzle/index.html` in a browser.
