# Breathing Exercise

A Headspace-inspired, guided breathing exercise for the browser: a warm, animated gradient backdrop, a softly pulsing circle that expands and contracts with your breath, and a gentle chime at each phase change.

## Features

- **Three breathing patterns**: Box (4-4-4-4), Calm 4-7-8, and Simple (4-6)
- **Session lengths**: 1, 3, or 5 minutes, tracked by a circular progress ring
- Animated breathing circle synced to each phase's exact duration
- Optional soft audio cues (togglable) generated with the Web Audio API — no external assets
- Cycle counter and a gentle completion screen

To use, open `breathing-exercise/index.html` in a browser.
